🔎 Image Finder

A simple and responsive Image Finder web application built using HTML, CSS and Vanilla JavaScript. It uses the Unsplash API to search and display images dynamically.

✨ Features

- 🔍 Search images using keywords
- 🖼️ Fetches images from Unsplash API
- 👤 Displays photographer profile image and name
- 📝 Displays image descriptions
- ➕ Load More button for additional images
- 🌿 Shows default images when the website loads
- 📱 Responsive design
- 🎨 Clean and modern white UI
- ✨ Smooth hover effects on image cards

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Unsplash API

⚙️ How It Works

1. Enter a keyword in the search box.
2. Click the Search button.
3. The application sends the request to the Unsplash API.
4. Matching images are displayed dynamically.
5. Click Load More to fetch additional results.
